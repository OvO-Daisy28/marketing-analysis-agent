# 简历与面试说明

项目名称：**营销分析 Agent｜公开工程复现项目**。

背景：面向营销运营分析与报告交付，使用公开电商数据，构建报表 Skill 与多轮研究 Loop，提供执行追踪、故障测试和可复现评测。

- **报表 Skill：**封装数据合同、受控 HTML 与 G2 配方，实现运行时取数、隔离预览、修改版本和人工确认发布，通过独立数值核验与浏览器测试检查交付链路。
- **研究 Loop：**持久化目标、假设、证据与结论，逐轮构建研究上下文，支持工具反馈、输入续接、无进展检测及预算停止。
- **执行可靠性与评测：**实现数据库租约、检查点、幂等写入和事件追踪；以真实 PostgreSQL 验证并发领取及恢复，完成 86 次真实模型对照运行并公开失败案例。

可引用的实测事实：31 项后端测试、2 项浏览器测试通过；181 个聚合结果通过独立 CSV 核验；两种版本均完成 40 个常规任务中的 38 个。注明样本与条件，不写“整体准确率 100%”或“成功率提升”。

原校企经历和此公开复现分别描述。该仓库采用 AI 辅助开发，能够解释需求取舍、核心实现、验证方法和已知不足，比声称每行代码都是手写更准确。原公司的规模、上线情况和业务收益不转移到此项目。
